웹 타로 카드 — API 사용 예제

이 페이지는 /taro에 정적으로 호스팅된 타로 카드 데이터를 외부 코드가 어떻게 호출하는지 보여주는 예제입니다. 백엔드 API는 없으며, 모든 데이터는 정적 JSON 파일입니다. CORS는 *로 열려 있어 다른 origin에서도 동일하게 호출할 수 있습니다.

1) Tarot 라이브러리로 한 줄 호출 (권장)

같은 페이지에서 ESM 모듈로 불러와 draw(n) / drawSpread(id)를 호출합니다.

<script type="module">
import { Tarot } from '/taro/tarot.js';

const tarot = await Tarot.load();
const result = tarot.drawSpread('three_card');   // 또는 tarot.draw(1)
console.log(result);
</script>
아직 실행 안 함

2) 라이브러리 없이 순수 fetch로 호출 (API처럼)

라이브러리를 안 쓰고 JSON만 받아도 됩니다. 카드를 뽑는 로직은 호출 측에서 직접 구현.

const res  = await fetch('/taro/cards/cards.json');
const data = await res.json();
const pick = data.cards[Math.floor(Math.random() * data.cards.length)];

console.log(pick.id, pick.name_ko, pick.keywords_upright);
// 이미지 URL은 'cards/...' 상대 경로이므로 base와 결합:
const imageUrl = new URL(pick.image, 'https://your-host/taro/').href;
아직 실행 안 함

3) 다른 도메인 / 다른 페이지에서 호출

완전히 별개 origin에서도 동일하게 동작합니다 (CORS 열려 있음):

// 다른 사이트의 페이지에서:
const url = 'http://<이 서버의 호스트>:21080/taro/cards/cards.json';
const data = await (await fetch(url)).json();
console.log(data.count_cards, '장 로드');

또는 라이브러리를 절대 URL로 import:

const { Tarot } = await import('http://<호스트>:21080/taro/tarot.js');
const tarot = await Tarot.load();
console.log(tarot.draw(1));

메인 데모 페이지: /taro/ · 라이브러리 소스: /taro/tarot.js · 카드 데이터: /taro/cards/cards.json

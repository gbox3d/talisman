웹 타로 카드 — API 사용 예제

타로 카드 데이터를 외부 코드가 어떻게 호출하는지 보여주는 예제입니다. 두 가지 경로가 있습니다 — ① 라이브 API(서버리스 엣지가 한 번의 GET으로 뽑아줌)와 ② 정적 호스팅(백엔드 없이 JSON 파일 직접 호출, 뽑기는 호출 측에서). 모두 CORS가 *로 열려 있어 다른 origin·앱 인벤터에서도 동일하게 호출됩니다.

정적 API base 주소

정적 JSON/이미지 파일은 GitHub Pages의 https://gbox3d.github.io/talisman 아래에 있습니다. 코드에서는 이 값을 STATIC_BASE로 두고 /cards/... 경로를 붙여 호출하면 됩니다. 

const STATIC_BASE = 'https://gbox3d.github.io/talisman';

const ids = await fetch(`${STATIC_BASE}/cards/ids.json`).then(r => r.json());
const card = await fetch(`${STATIC_BASE}/cards/major_00_fool.json`).then(r => r.json());
const imageUrl = new URL(card.image, `${STATIC_BASE}/`).href;

대표 정적 엔드포인트: /cards/ids.json, /cards/cards.json, /cards/{id}.json, /spreads.json. 무작위 뽑기까지 한 번에 처리하려면 아래 라이브 API base https://talisman.gbox3d.deno.net을 사용합니다.

★ 라이브 API — 한 번의 GET으로 뽑기 (/api/{n})

서버리스 엣지 talisman.gbox3d.deno.net가 겹치지 않게 카드를 뽑아 이미지 + 타로 정보를 한 번의 GET으로 돌려줍니다. 정적 2-step(목록 → 무작위 → 카드)이 필요 없습니다. 아래 버튼이 실제 라이브 엣지를 호출합니다. 

// 무작위 3장 — 한 번의 GET (2-step 불필요)
const draw = await fetch('https://talisman.gbox3d.deno.net/api/3').then(r => r.json());
draw.cards.forEach(c => console.log(c.name_ko, c.orientation, c.image_url));

// 과거-현재-미래 스프레드
const spread = await fetch('https://talisman.gbox3d.deno.net/api/spread/three_card').then(r => r.json());

요청
· GET /api/{n} — 카드 n장(1~78) 비복원 뽑기. ?reversed=false면 전부 정방향.
· GET /api/spread/{id} — 스프레드로 뽑기. id: single / three_card / situation_action_outcome.
· GET / — 사용법(엔드포인트 목록).
응답 — { count, spread, cards[] }. 각 카드 객체:
· id, name_ko/name_en, arcana/suit/number
· orientation(upright|reversed), keywords(그 방향에 맞춰 고른 배열)
· image_url — 완성된 절대 URL이라 그대로 <img src>에 사용, license
· 스프레드 응답이면 카드마다 position_key / position_name_ko 추가. 

아직 실행 안 함

1) Tarot 라이브러리로 한 줄 호출 (정적, 권장)

같은 페이지에서 ESM 모듈로 불러와 draw(n) / drawSpread(id)를 호출합니다.

<script type="module">
import { Tarot } from 'https://gbox3d.github.io/talisman/tarot.js';

const tarot = await Tarot.load({
  baseUrl: 'https://gbox3d.github.io/talisman/',
});
const result = tarot.drawSpread('three_card');   // 또는 tarot.draw(1)
console.log(result);
</script>
아직 실행 안 함

2) 라이브러리 없이 순수 fetch로 호출 (API처럼)

라이브러리를 안 쓰고 JSON만 받아도 됩니다. 카드를 뽑는 로직은 호출 측에서 직접 구현.

const STATIC_BASE = 'https://gbox3d.github.io/talisman';

const res  = await fetch(`${STATIC_BASE}/cards/cards.json`);
const data = await res.json();
const pick = data.cards[Math.floor(Math.random() * data.cards.length)];

console.log(pick.id, pick.name_ko, pick.keywords_upright);
// 이미지 URL은 'cards/...' 상대 경로이므로 base와 결합:
const imageUrl = new URL(pick.image, `${STATIC_BASE}/`).href;
아직 실행 안 함

3) 다른 도메인 / 다른 페이지에서 호출

완전히 별개 origin에서도 동일하게 동작합니다 (CORS 열려 있음):

// 다른 사이트의 페이지에서:
const STATIC_BASE = 'https://gbox3d.github.io/talisman';
const data = await fetch(`${STATIC_BASE}/cards/cards.json`).then(r => r.json());
console.log(data.count_cards, '장 로드');

또는 라이브러리를 절대 URL로 import:

const { Tarot } = await import('https://gbox3d.github.io/talisman/tarot.js');
const tarot = await Tarot.load({
  baseUrl: 'https://gbox3d.github.io/talisman/',
});
console.log(tarot.draw(1));

정적 API base: gbox3d.github.io/talisman · 라이브 API: talisman.gbox3d.deno.net · 메인 데모 페이지: /talisman/ · 라이브러리 소스: /talisman/tarot.js · 카드 데이터: /talisman/cards/cards.json
